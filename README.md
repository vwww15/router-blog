
# Блог на React Router v7

## Опис проєкту

Навчальний React-застосунок, створений у межах лабораторної роботи з маршрутизації.

Проєкт реалізовано за допомогою React, Vite та React Router v7.

## Виконані рівні

### Рівень 1 — Базовий блог
- Головна сторінка зі списком постів
- Сторінка окремого поста
- Сторінка «Про нас»
- Обробка невідомих адрес (404)
- Навігація між сторінками

### Рівень 2 — Фільтрація та редиректи
- Пошук постів
- Query-параметри в URL
- Збереження пошуку після оновлення
- Перенаправлення /blog на /

### Рівень 3 — Робота з API
- Завантаження постів із JSONPlaceholder
- Використання loader
- Обробка помилок через ErrorBoundary
- Індикатор завантаження
- Ліниве завантаження сторінки «Про нас»

### Рівень 4 — Авторизація та тестування
- Контекст авторизації AuthContext
- Сторінка входу
- Захищений маршрут /admin
- Вихід із системи
- Автоматичні тести Vitest

## Маршрути

| Маршрут | Призначення |
|---------|-------------|
| / | Головна сторінка |
| /posts/:postId | Сторінка поста |
| /about | Про нас |
| /login | Вхід |
| /admin | Захищена сторінка |
| /blog | Редирект на головну |
| * | Сторінка 404 |

## Запуск проєкту

Потрібен Node.js 24 LTS.

Встановлення залежностей:

npm install

Запуск локального сервера:

npm run dev

Адреса локального сайту:

http://localhost:5173/

## Тестування

Запуск тестів:

npm test -- --run

Результат: 4 тести успішно пройдено.

## Збірка

npm run build

Готові файли розміщуються в папці dist.
